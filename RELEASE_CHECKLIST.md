# Inventory Overhaul — release checklist

## 1. Установка и обновление

- [ ] Чистая установка через UtopianLauncher проходит без ошибок.
- [ ] Мод отображается как `Inventory Overhaul`.
- [ ] `InventoryOverhaul.dll` выбран основной DLL.
- [ ] `OynonTools.dll` распознан как shared dependency.
- [ ] Нет ошибок `Listed DLL is missing` и `LoadOrder cannot move backwards`.
- [ ] Обновление поверх предыдущей версии не оставляет старые `utopian_*` файлы.
- [ ] Удаление мода возвращает игру в рабочее состояние.
- [ ] Игра запускается после удаления мода.

## 2. Запуск, загрузки и сохранения

Проверить за Бакалавра, Гаруспика и Клару:

- [ ] Новая игра запускается.
- [ ] Повторный запуск новой игры без перезапуска приложения не вызывает краш.
- [ ] Старое сохранение загружается.
- [ ] Quicksave/quickload работают.
- [ ] Обычное сохранение и загрузка работают.
- [ ] Несколько последовательных загрузок не снижают FPS.
- [ ] Быстрая загрузка во время инициализации модов не вызывает краш.
- [ ] Стартовый hub и финальный мир не вызывают краш.
- [ ] Позиции предметов и quickslots сохраняются после save/load.

## 3. Основное окно инвентаря

Проверить на `800x600`, `1024x768`, `1280x1024` и `1920x1080`:

- [ ] Окно правильно центрировано.
- [ ] Фон соответствует персонажу.
- [ ] Фон не растянут, не обрезан и не имеет чёрных полос.
- [ ] Силуэт персонажа помещается в левую панель.
- [ ] HEAD/BODY/HANDS/FEET/WEAPON совпадают с визуальными слотами.
- [ ] Деньги, DROP, кнопка `?` и пагинация находятся на своих местах.
- [ ] Часы читаются и не выходят за границы панели.
- [ ] Подсказки предметов работают и не мерцают после drag-and-drop.
- [ ] Пустые слоты имеют прозрачность `0.78`.
- [ ] Занятые слоты и предметы не становятся прозрачными.
- [ ] После открытия нет случайной ghost-иконки.

## 4. Сетка и пагинация

- [ ] Вместимость рюкзака — 56 занятых ячеек без учёта экипировки.
- [ ] Новые предметы занимают первые свободные ячейки слева направо и сверху вниз.
- [ ] Остальные предметы не меняют позиции при добавлении нового.
- [ ] Кнопки `<` и `>` нажимаются.
- [ ] Счётчик показывает правильную страницу.
- [ ] Неактивная стрелка не подсвечивается и не переключает страницу.
- [ ] Пагинация появляется только при наличии второй страницы.
- [ ] Все видимые слоты обеих страниц принимают предметы.
- [ ] `Ctrl + ЛКМ` переносит предмет на другую страницу.
- [ ] Drag-hover над стрелкой переключает страницу через одну секунду.
- [ ] После переключения предмет можно положить в выбранную ячейку.
- [ ] Подсказка пагинации описывает оба способа переключения.

## 5. Drag-and-drop внутри рюкзака

- [ ] Предмет переносится именно в выбранный слот.
- [ ] Остальные предметы не перемешиваются.
- [ ] Ghost-иконка имеет правильный размер.
- [ ] Курсор целиком виден поверх ghost-иконки.
- [ ] Целевой слот получает обводку.
- [ ] Alpha Tablets и другие нестандартные предметы имеют ghost-иконку.
- [ ] Стеки корректно объединяются.
- [ ] Перенос между страницами не создаёт дубликаты.
- [ ] Tooltip не вспыхивает на старой позиции после drop.

## 6. Экипировка

- [ ] HEAD экипируется и снимается.
- [ ] BODY экипируется и снимается.
- [ ] HANDS экипируется и снимается.
- [ ] FEET экипируется и снимается.
- [ ] WEAPON экипируется и снимается.
- [ ] Предмет переносится из сетки на куклу.
- [ ] Предмет переносится с куклы в выбранную ячейку.
- [ ] Правый клик снимает экипированный предмет.
- [ ] Снятый предмет занимает первую свободную ячейку.
- [ ] Замена экипировки не перемешивает рюкзак.
- [ ] Экипированный предмет не дублируется в сетке.
- [ ] Снятие запрещено при заполненном рюкзаке.
- [ ] При отказе показывается сообщение «Инвентарь полон».
- [ ] Переключение оружия не вызывает заметный фриз.

## 7. DROP и выбрасывание

- [ ] Drag-and-drop в DROP выбрасывает предмет.
- [ ] На земле создаётся мешок, предмет не исчезает.
- [ ] `Ctrl + ЛКМ` выбрасывает одну единицу стака.
- [ ] `Shift + ЛКМ` выбрасывает весь стак.
- [ ] Подсказка DROP описывает актуальные shortcuts.
- [ ] DROP скрыт при открытом контейнере или трупе.
- [ ] Переназначенная клавиша holster обрабатывается.
- [ ] Holster оружия выбрасывает его на землю, а не возвращает в рюкзак.
- [ ] Выброшенный мешок открывается без softlock.
- [ ] После изъятия последнего предмета мешок корректно закрывается.

## 8. Контейнеры

Проверить ящик, шкаф/тумбочку, мусорный бак и выброшенный мешок:

- [ ] Слева отображается силуэт контейнера.
- [ ] Слоты органов отсутствуют у всех персонажей.
- [ ] Предметы контейнера отображаются без перестановки.
- [ ] Drag-and-drop работает в обе стороны.
- [ ] Предмет попадает в выбранную ячейку.
- [ ] Правый клик переносит предмет между инвентарями.
- [ ] `Shift + ПКМ` переносит весь стак в обе стороны.
- [ ] Стеки объединяются сразу.
- [ ] Исходный слот очищается без визуальных дубликатов.
- [ ] Пагинация контейнера появляется только при необходимости.
- [ ] Пагинация игрока доступна в окне контейнера.
- [ ] Обмен с контейнером не перемешивает рюкзак.
- [ ] Пустой контейнер можно закрыть через Esc.
- [ ] Переполненный контейнер показывает понятное сообщение.

## 9. Трупы

- [ ] У трупов отображается `doll.png`, а не силуэт контейнера.
- [ ] Это работает для сюжетных трупов.
- [ ] Это работает для убитых игроком NPC.
- [ ] Это работает у Бакалавра.
- [ ] Это работает у Клары.
- [ ] Это работает у Гаруспика.
- [ ] Окно не вызывает softlock и закрывается по Esc.
- [ ] У Бакалавра и Клары слоты органов полностью скрыты.
- [ ] У Гаруспика отображаются четыре слота органов.
- [ ] После извлечения органа слот блокируется изображением скальпеля.
- [ ] В заблокированный слот нельзя вернуть орган или другой предмет.
- [ ] Ограничение вместимости трупа выводит корректное отдельное сообщение.
- [ ] Предметы переносятся в обе стороны без дубликатов.
- [ ] Пагинация игрока работает при луте трупа.

## 10. Вместимость и переполнение

- [ ] В одну категорию можно добавить больше 12 уникальных предметов.
- [ ] Ограничение категорий снято только у игрока.
- [ ] При 56 занятых ячейках нельзя добавить новый уникальный стек.
- [ ] Пополнение существующего стака при 56 ячейках разрешено.
- [ ] При отказе предмет остаётся в исходном контейнере.
- [ ] Предмет не исчезает при неудачном переносе.
- [ ] Новый предмет, добавленный скриптом/консолью, падает на землю.
- [ ] При переполнении падает новый предмет, а не старый из рюкзака.
- [ ] Частично поместившийся стак разделяется корректно.
- [ ] Сообщение «Инвентарь полон» локализовано и не спамит.
- [ ] Сохранения с количеством предметов больше лимита не повреждаются.

- [ ] Наведение на предмет и клавиша `1–0` назначают слот.
- [ ] Цифра отображается без чёрного квадрата.
- [ ] Назначение работает за всех трёх персонажей.
- [ ] Назначения сохраняются после save/load.
- [ ] Quickslots доступны после начала игры.
- [ ] Одиночный расходуемый предмет применяется один раз и исчезает.
- [ ] Из стака расходуется ровно одна единица.

- [ ] После исчерпания показывается сообщение об отсутствии предмета.
- [ ] HUD-индикация использования появляется.
- [ ] Бутылка воды создаёт пустую бутылку.

- [ ] Dead Gruel и другие созданные предметы не перемешивают новый инвентарь.

- [ ] После закрытия FPS возвращается к исходному.
- [ ] Несколько save/load не ухудшают FPS.
- [ ] За Клару нет отдельной сильной просадки.
- [ ] Перемещение внутри сетки выполняется без задержки.
- [ ] Обмен с контейнером/трупом не вызывает микрофриз.
- [ ] Экипировка, особенно оружие, не вызывает заметный фриз.

## Релиз-блокеры

Релиз запрещён при любом из следующих дефектов:

- краш или softlock;
- исчезновение либо дублирование предмета;
- повреждение сохранения;
- неработающий Esc;
- невозможность закрыть контейнер/труп;
- постоянная просадка FPS после закрытия инвентаря;
- неправильная активация или расход предмета через quickslot.
